# Almas Smart Learn

Windows-та Android телефонының root touch оқиғаларын үйреніп, оларды PC пернелеріне bind жасайтын қолданба.

## Қолдану
1. Телефонда USB debugging қосыңыз.
2. Телефонды USB арқылы қосып, Magisk root рұқсатын беріңіз.
3. `AlmasSmartLearn.exe` ашыңыз.
4. **Телефонды қосу** батырмасын басыңыз.
5. **Жаңа bind үйрету** басыңыз.
6. Телефонда ойындағы қажетті батырманы бір рет басыңыз.
7. Ноутбуктан бекіткіңіз келетін пернені басыңыз.
8. Профиль JSON ретінде `profiles` папкасына сақталады.

## Build
GitHub Actions әр push кезінде Windows x64 self-contained EXE жинайды. .NET орнату қажет емес.
