# ONAY! — интерфейс макеті

Бұл ONAY! стиліндегі дербес веб-интерфейс макеті. Нақты ONAY! төлем серверіне қосылмаған.

## Өңдеу

- `index.html`: мәтіндер, түймелер және HTML беттердің құрылымы
- `styles.css`: дизайн, шрифт, түстер, өлшемдер
- `app.js`: батырмалардың жұмысы, навигация, ашылатын терезелер
- `assets/`: иллюстрациялар мен жарнама суреттері

Бұл жоба `almas-offikal` репозиторийіндегі `3d-viewer/onay/` қалтасында орналасқан және бар `Deploy Almas 3D Viewer to Pages` жұмыс ағыны арқылы жариялануға арналған.

Сайт — тек UI демонстрациясы: нақты ақша аударымдары, төлемдер, баланс деректері іске асырылмаған.
